# monthly-summary

引数：`YYYY-MM`（省略時は直近の完了月）。

## 手順

1. 対象月の `weeks/*.md` をすべて読む（月をまたぐ週は開始日で判定）
2. `profile/profile.md` と `config/perspectives.md` を読む
3. `monthly/YYYY-MM.md` を作る（下記フォーマット）
4. `profile/profile.md` を更新する
   - 得意・課題は **2 週以上で観測されたこと** だけを追加する
   - 観測ログに根拠の週（例：2026-W03, W05）を必ず書く
   - 既存項目は、観測が続いていれば維持、解消していれば「状態」を更新する
   - 1 週だけの出来事は「観測ログ」に候補として残すのみ
5. 変更点（追加・更新した項目）を要約してユーザーに見せる。確認前に確定させない

## monthly/YYYY-MM.md のフォーマット

```markdown
# YYYY-MM 月次サマリ

参照：weeks/YYYY-Wxx.md（一覧）

## 今月の要点（3行以内）

## 目標の達成状況
| 週 | 目標 | 結果 |

## 繰り返し出てきたこと
- 事実（根拠の週）

## うまくいった型（再現できる形で）

## 詰まりが続いていること

## 他者からの声（まとめ）

## 来月に試すこと（1〜3個）
```

## ルール

- **入力にない人格・性格の断定はしない**。「〜な人」ではなく「〜という行動が N 週で観測された」と書く
- 他者からの声が乏しい月は、その旨を明記し、自己評価に偏っている可能性を書く
- 週次に書かれていない内容を補わない
