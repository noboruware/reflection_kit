# perspectives.md — 振り返りの観点

`/weekly-reflection` が毎回読み込む。自分の業務に合わせて編集する。
ここを変えれば、質問の観点が変わる。

---

## 週初（目標）

- 今週のゴール（最大3つ。「終わった」と判断できる形で）
- 今週注意すること（先週の「次の一手」から）
- 今週の役割（分析担当 / リード / 顧客対応 など）

## 週末（振り返り）

各観点で 1〜2 個の質問をする。全部を毎回聞く必要はない。

| 観点 | 問い |
|------|------|
| 進捗 | 目標は達成できたか。できなかった理由は何か |
| 大変だったこと | 何に時間・気力を使ったか |
| 工夫したこと | 自分から変えたやり方は何か |
| うまくいった瞬間 | 何をして、何が良かったのか（再現できる形で） |
| 詰まった点 | どこで止まり、どう抜けたか（抜けていないなら何が要るか） |
| 他者からの声 | 上司・顧客・チームから言われたこと（そのまま） |
| 次の一手 | 来週やること・試すこと（1〜3個） |

## 役割別の追加観点（任意）

- リード：メンバーの動きを妨げていないか、何を任せたか
- 顧客対応：期待値のずれはなかったか、確認したことは何か
- 分析：仮説を先に置いたか、結果の解釈を人に説明できるか

## 書くときの型

- **Facts**：あったこと、やったこと、言われたこと
- **Interpretation**：そこから自分がどう考えたか
